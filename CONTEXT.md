# HomeChore

HomeChore describes a household's recurring duties, meals, and daily plans in language shared by the people who organize and carry out the work.

## Language

**Household**:
The home whose identity, people, routine, and schedule are configured together.
_Avoid_: Account, tenant

**Assignee**:
A named person, or the shared option, responsible for a planned duty or meal.
_Avoid_: User, helper, worker

**Routine Period**:
An ordered, named portion of a day with a start and end time, used to group duties and offer exact times at 30-minute intervals.
_Avoid_: Group, grouping, time slot

**Duty**:
A household chore or activity that can be placed into a day's Routine Period and assigned to an Assignee.
_Avoid_: Task, job

**Meal Option**:
A reusable dish that can be selected as a meal part in the daily plan.
_Avoid_: Meal item, recipe

**Media Asset**:
An uploaded meal image stored as a processed file in the Household's local media directory and referenced by its filename.
_Avoid_: Blob, database image, base64 image

**Local Edition**:
The complete open-source HomeChore application run by a Household on a trusted private network without user accounts.
_Avoid_: Free tier, community tier
