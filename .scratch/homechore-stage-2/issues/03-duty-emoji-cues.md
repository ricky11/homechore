# 03: Duty Emoji Cues

**What to build:** Make recurring Duties quicker to scan by adding local emoji suggestions and a manual override, with the selected emoji visible wherever a Duty is planned.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent
