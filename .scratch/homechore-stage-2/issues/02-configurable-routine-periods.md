# 02: Configurable Routine Periods

**What to build:** Let a household manager tailor the daily routine using two to six valid Routine Periods, configurable off-days, and optional 30-minute Duty times while protecting planned work from accidental removal.

**Blocked by:** 01: Household Identity and Management.

**Status:** resolved

- [x] The initial Routine Periods are Morning (06:30-11:00), Midday (11:00-15:00), and Evening (15:00-20:00).
- [x] A household manager can add, rename, reorder, and edit Routine Period ranges while invalid or overlapping ranges are rejected.
- [x] Optional Duty times are selectable in 30-minute increments within the assigned Routine Period.
- [x] A Routine Period with existing Duties cannot be removed until those Duties are moved.
- [x] Assignee off-days replace fixed names in Daily and Weekly availability labels.
- [x] The production build passes.
